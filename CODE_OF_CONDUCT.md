# Code of Conduct

This project follows the Contributor Covenant Code of Conduct.

## Our Standards

Examples of behavior that contributes to a positive environment:

- Being respectful and constructive.
- Accepting feedback gracefully.
- Focusing on what is best for the project and its users.

Examples of unacceptable behavior:

- Harassment, insults, or personal attacks.
- Publishing private information without permission.
- Disruptive or bad-faith participation.

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, issues, and pull requests that do not align with this Code of Conduct.
